# gmili-commerce-laravel-next-native

Le projet Gmili Jewelry consiste à concevoir et développer une plateforme e-commerce spécialisée dans la vente d’accessoires en acier, destinée à un large public. 
L’objectif est de proposer une expérience d’achat moderne,
intuitive et personnalisée, tout en intégrant progressivement des fonctionnalités avancées telles que la fidélisation et l’intelligence artificielle. 
La plateforme permet aux utilisateurs de parcourir un catalogue structuré de produits, de rechercher et filtrer les articles selon leurs préférences, d’ajouter des produits au panier, de passer des commandes sécurisées et de suivre leurs achats. Elle intègre également un système de gestion des comptes utilisateurs, des adresses, des commandes et des paiements. 


Objectifs du projet Le projet vise à :
développer une plateforme e-commerce complète et évolutive,
offrir une expérience utilisateur fluide et intuitive, mettre en place un système de fidélité basé sur des points, 
proposer des abonnements avec avantages personnalisés, intégrer des outils d’analyse et de personnalisation, 
exploiter l’intelligence artificielle pour améliorer les recommandations et la recherche. 


Architecture technique Le système repose sur une architecture moderne en plusieurs couches : 
Frontend web développé avec Next.js, 
Application mobile développée avec React Native, Backend API développé avec Laravel, 
Base de données PostgreSQL pour le stockage des données, Redis pour le cache et les traitements asynchrones, 
Stripe pour la gestion des paiements, 
API d’intelligence artificielle pour les recommandations et l’assistance. 

Vision du projet Le projet est structuré en deux phases principales : 

Version 1 (V1) Une plateforme e-commerce fonctionnelle incluant :
gestion des utilisateurs, catalogue produits, panier et commande, paiement sécurisé, fidélité simple, notifications.
